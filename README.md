# ستوديو الصوت · Voice Studio

تطبيق ويب (PWA) احترافي لتسجيل وتحرير ومعالجة الصوت على الهاتف — بتصميم مستوحى من CapCut. كل المعالجة تتم محليًا على الجهاز ولا يُرفع أي صوت.
A pro-grade voice recorder / editor / mastering PWA for phones. Everything runs locally.

## المميزات / Features
- **التسجيل**: عداد ومؤشر مستوى حي + كاشف تقطيع، موجة حية أو طيف، إيقاف مؤقت، علامات أثناء التسجيل، عدّ تنازلي، اختيار الميكروفون، ستريو، مراقبة بالسماعات، إبقاء الشاشة مضاءة. عند الضغط على زر التسجيل تظهر الخيارات في لوحة سفلية (إلغاء الضوضاء/الصدى/AGC وتضخيم الدخل).
- **التنقية الاحترافية**: إزالة ضوضاء طيفية (مع التقاط بصمة الضوضاء)، بوابة ضوضاء، إزالة طنين الكهرباء 50/60Hz، قص الترددات المنخفضة/العالية، De‑esser.
- **التحرير**: خط زمني بمؤشر ثابت (اسحب للتمرير، قرصة للتكبير)، تحديد بمقابض، قص/إبقاء/كتم/عكس/نسخ/لصق/تكرار، تضخيم التحديد، تلاشي، إدراج صمت، حذف الصمت تلقائيًا، تراجع/إعادة، علامات، مقارنة قبل/بعد (A/B).
- **المعالجة**: إيكوالايزر 7 نطاقات برسم الاستجابة، ضاغط، دفء/تشبّع، صدى مكان (غرفة/استوديو/قاعة/**مسجد**/كهف)، Echo/Delay، Chorus، تغيير النغمة والسرعة دون تشويه (WSOLA)، روبوت، تسوية الجهارة LUFS + محدّد قمم.
- **قوالب جاهزة**: تحسين تلقائي، بودكاست، تعليق صوتي، **تلاوة قرآن**، صدى المسجد، أذان، إذاعة، ريلز/تيك توك، صوت عميق، هاتف، ميجافون، روبوت، كهف.
- **التصدير**: WAV (16/24/32‑float) و MP3 (128–320kbps)، مشاركة مباشرة، تصدير التحديد فقط.
- **المكتبة**: حفظ تلقائي على الجهاز (IndexedDB)، بحث، إعادة تسمية، تكرار، استيراد ملفات صوت/فيديو.
- واجهة عربية/إنجليزية (RTL/LTR)، يعمل دون اتصال بعد أول تحميل، قابل للتثبيت على الشاشة الرئيسية.

## التشغيل
الميكروفون يتطلب HTTPS (أو localhost):
```bash
python3 -m http.server 8080   # ثم افتح http://localhost:8080
```
للنشر: ادمج الفرع في `main` وفعّل GitHub Pages (Source: GitHub Actions) — يوجد workflow جاهز في `.github/workflows/pages.yml`.

## البنية
`js/audio.js` سلسلة التأثيرات + القياس + الترميز · `js/worker.js` تنقية/تمديد زمني في Web Worker · `js/editor.js` المحرر · `js/tools.js` لوحات الأدوات · `js/record-view.js` شاشة التسجيل.
