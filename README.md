# ستوديو الصوت · Voice Studio

تطبيق **Flutter** احترافي (أندرويد / iOS) لتسجيل وتنقية وتحرير ومعالجة الصوت على الهاتف، بتصميم مستوحى من CapCut وبواجهة عربية/إنجليزية.
كل المعالجة تتم محليًا على الجهاز ولا يُرفع أي صوت.

## المميزات
- **التسجيل**: مؤشر مستوى حي + كاشف تقطيع + موجة حية، إيقاف مؤقت، علامات أثناء التسجيل، عدّ تنازلي، اختيار الميكروفون، ستريو، تضخيم الدخل، إبقاء الشاشة مضاءة. عند بدء التسجيل تظهر لوحة الخيارات من الأسفل (إلغاء الضوضاء/الصدى/AGC).
- **التنقية**: إزالة ضوضاء طيفية احترافية (مع التقاط بصمة الضوضاء)، بوابة ضوضاء، إزالة طنين 50/60Hz، قص الترددات المنخفضة/العالية، De-esser.
- **التحرير**: خط زمني بمؤشر ثابت (اسحب للتمرير، قرصة للتكبير)، تحديد بمقابض، قص/إبقاء/كتم/عكس/نسخ/لصق/تكرار، تضخيم التحديد، تلاشي، إدراج صمت، حذف الصمت تلقائيًا، تراجع/إعادة، علامات، مقارنة قبل/بعد (A/B).
- **المعالجة**: إيكوالايزر 7 نطاقات برسم الاستجابة، ضاغط، دفء/تشبّع، صدى مكان (غرفة/استوديو/قاعة/**مسجد**/كهف)، Echo/Delay، Chorus، تغيير النغمة والسرعة دون تشويه (WSOLA)، روبوت، تسوية الجهارة LUFS + محدّد قمم.
- **قوالب**: تحسين تلقائي، بودكاست، تعليق صوتي، **تلاوة قرآن**، صدى المسجد، أذان، إذاعة، ريلز، صوت عميق، هاتف، ميجافون، روبوت، كهف.
- **التصدير**: WAV (16/24/32-float) و MP3 (128–320kbps)، مشاركة أو حفظ في مكان تختاره، تصدير التحديد فقط.
- **المكتبة**: حفظ تلقائي على الجهاز، بحث، إعادة تسمية، تكرار، استيراد ملفات WAV.

## البناء
```bash
flutter pub get
flutter test                 # اختبارات محرك الصوت
flutter run                  # تشغيل على جهاز/محاكي
flutter build apk --release  # ملف APK (build/app/outputs/flutter-apk/app-release.apk)
```
يوجد workflow جاهز `.github/workflows/build-apk.yml` يبني الـ APK على GitHub ويرفعه كـ Artifact.

## البنية
- `lib/dsp/` محرك الصوت (Dart خالص): تنقية طيفية، ديناميكس، ريفيرب، ستريتش، LUFS، WAV.
- `lib/services/` المسجّل، المكتبة، المشغّل، وحدة تحكم المحرر.
- `lib/ui/` الشاشات واللوحات والخط الزمني.
- `legacy_web/` النسخة الأولى (PWA) محفوظة للرجوع إليها فقط.
